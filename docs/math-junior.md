# 수학놀이터 · 유아·초등

## 구성

- `math-junior.html`: 수학놀이터 · 유아·초등 전용 게임 페이지.
- `math-junior-problems.js`: 화면·저장소·네트워크와 분리된 문제 생성기.
- `math-level.html`: 수학게임 · 중1~고3 전용 게임 페이지. 기존 레벨 번호와 학습 기록 형식을 유지합니다.
- 게임 목록에는 두 항목을 별도로 표시하고, 게임 내부에는 서로 이동하는 링크를 두지 않습니다. 기존 수학관리 설정과 문제 수 합산 정책은 유지합니다.

## 대표 학습 영역

이 게임은 학년별 **대표 영역 연습용**입니다. 모든 교과 단원을 포함하거나 표준화된 학력 진단을 제공하지 않습니다.

- 유아 1: 그림을 보며 1~10 수 세기.
- 유아 2: 많고 적음 비교, 모양의 반복 규칙.
- 유아 3: 동그라미·세모·네모·별 구별.
- 초1: 한 자리 덧셈·뺄셈, 몇십 몇, 도형의 변.
- 초2: 두 자리 덧셈, 곱셈구구, 시각, 길이.
- 초3: 곱셈·나눗셈, 분수의 뜻, 길이.
- 초4: 큰 수, 각도, 소수 덧셈, 직사각형 둘레.
- 초5: 분수, 직사각형 넓이, 평균, 소수 덧셈.
- 초6: 백분율, 원의 넓이, 직육면체 부피, 소수 나눗셈.

학년 표시는 학습 경로를 돕는 구분이며 일부 문항에는 이전 학년 복습이 포함됩니다. 유아 과정은 보호자가 질문을 읽어주며 함께 사용하는 것을 권장합니다.

## 개발·배포 주의

- 새 생성기 파일은 `server/static-policy.js`의 공개 자산 허용 목록에 포함되어야 합니다.
- `node scripts/build-static.js` 실행 후 `.static-site/`에 HTML과 생성기가 모두 포함되었는지 확인합니다.
- 실행 중인 Node 서버는 `static-policy` 모듈을 캐시합니다. 정책 수정은 실제 서비스에 반영되었는지 HTTP 응답으로 별도 확인해야 합니다.
- 정답 위치는 섞고, 수치형 오답은 정답보다 작은 값과 큰 값을 섞어 최솟값 선택만으로 정답을 추측하지 못하게 합니다.
- 학습 기록은 브라우저 저장소에 보존되며 기기·브라우저·사이트 주소가 달라지면 자동 동기화되지 않습니다.

## 검증

```sh
node --test tests/math-junior-problems.test.js tests/math-junior-choice-balance.test.js tests/math-junior-static.test.js
node --test tests/math-junior-ui.test.js
```

브라우저 검증에는 Playwright가 필요합니다. 해당 테스트가 지원하는 `PLAYWRIGHT_PATH`로 설치 위치를 지정할 수 있습니다. WebKit 테스트는 Safari 엔진 계열 모의 검증이며 실제 아이폰 기기 테스트를 대신하지 않습니다.
