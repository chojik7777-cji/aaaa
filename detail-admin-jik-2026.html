공유노트 비밀번호 관리

Mac mini 로컬 전용입니다. 맥미니/터널에서만 변경되며 Vercel에는 동기화되지 않습니다.

노트 로그인과 별도로 관리자 인증이 필요합니다. 현재 비밀번호는 표시하지 않습니다.

보안 기록·알림과 서버 IP 잠금은 맥미니/터널의 관리자·현황판·노트 A/B·수학관리·수학게임 인증에 적용됩니다. 동일 실제 IP에서 해당 인증 비밀번호를 5회 틀리면 1시간 동안 로그인이 잠깁니다. 브라우저가 아닌 서버가 남은 기회와 잠금을 판정합니다. Vercel은 기존 브라우저 잠금을 유지하며 비밀번호 오류는 수집되지 않습니다.

노트 A 방 목록 (note.html)

「방 삭제」는 방을 목록에서 제거하고 기존 로그인을 해제합니다. 본문·첨부·백업은 보존되며 같은 방 이름은 재사용할 수 없습니다. 기본방(default)은 삭제할 수 없습니다.

NEW ROOM · 노트 A 새 방 생성

노트 A 새 방에 사용할 별도의 초기 비밀번호를 설정합니다. 방 이름은 영문 소문자·숫자·_·- 1~50자, 비밀번호는 8자 이상·256바이트 이하입니다. 기존 방과 비밀번호는 유지됩니다.

노트 A 기본방 빠른 선택

노트 A·B 모두 각 방 카드에서 비밀번호 변경과 내용·파일 초기화를 처리합니다. 초기화는 해당 방에만 적용되며 다른 방·비밀번호·로그인·백업은 유지됩니다.

노트 B 방 목록 (note2.html)

방을 열거나 선택해 비밀번호를 변경하세요. 목록에 없는 방은 아래 NEW ROOM에서 먼저 생성해 주세요. 내용·파일 초기화는 방을 유지하며 본문과 첨부파일만 삭제합니다.

선택한 방 비밀번호 변경

방 선택 버튼은 이 입력란으로 이동합니다. 실제 변경은 새 비밀번호 입력 후 저장할 때 적용됩니다.

선택한 노트 A 또는 B의 등록된 방별로 변경됩니다. 방 이름은 영문 소문자·숫자·_·- 1~50자입니다. 빈 입력은 기본방(default)을 선택합니다. 대문자는 거부되며 자동 변환되지 않습니다. 기존 대문자 방은 운영자 이관이 필요합니다. 여기에 이름을 입력해도 새 방이 생성되지 않습니다.

8자 이상, 256바이트 이하로 입력해 주세요. 저장하면 선택한 노트 A 또는 B 방의 기존 로그인만 해제됩니다. 다른 방과 관리자 로그인에는 영향이 없습니다. Mac mini 로컬/터널 전용이며 Vercel 비밀번호는 변경·동기화되지 않습니다.

NEW ROOM · 노트 B 새 방 생성

방 이름은 영문 소문자·숫자·_·- 1~50자, 비밀번호는 8자 이상·256바이트 이하입니다. 기존 방은 덮어쓰지 않습니다. 생성 즉시 지정한 비밀번호로 로그인할 수 있고 목록에도 나타납니다. 데이터 폴더는 첫 저장 또는 파일 업로드 시 만들어집니다.

보안 기록

15분 이내 동일 IP·페이지·방에서 비밀번호가 연속 5회 이상 실패하면 기록합니다. Mac mini 로컬/터널 전용입니다.

기기 ID는 무작위 브라우저 식별자이며 MAC 주소가 아닙니다. 쿠키 삭제 또는 다른 브라우저 사용 시 바뀔 수 있습니다. 브라우저·OS·기기 ID는 위조 가능하므로 신원을 증명하지 않습니다.
