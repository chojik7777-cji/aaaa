공유노트 비밀번호 관리

Mac mini 로컬 전용입니다. 맥미니/터널에서만 변경되며 Vercel에는 동기화되지 않습니다.

노트 로그인과 별도로 관리자 인증이 필요합니다. 현재 비밀번호는 표시하지 않습니다.

노트 A 관리 (note.html)

노트 A 기본방의 본문·첨부파일을 삭제하고 버전을 0으로 초기화합니다. 비밀번호·로그인과 다른 방은 유지됩니다. 실행 전 확인창이 표시됩니다.

노트 B 방 목록 (note2.html)

방을 열거나 선택해 비밀번호를 변경하세요. 목록에 없는 방은 아래 NEW ROOM에서 먼저 생성해 주세요. 내용·파일 초기화는 방을 유지하며 본문과 첨부파일만 삭제합니다.

노트 B는 등록된 방별로 변경됩니다. 방 이름은 영문 소문자·숫자·_·- 1~50자입니다. 대문자는 거부되며 자동 변환되지 않습니다. 기존 대문자 방은 운영자 이관이 필요합니다. 여기에 이름을 입력해도 새 방이 생성되지 않습니다.

8자 이상, 256바이트 이하로 입력해 주세요. 저장하면 노트 A 또는 선택한 노트 B 방의 기존 로그인만 해제됩니다. 다른 방과 관리자 로그인에는 영향이 없습니다. Mac mini 로컬/터널 전용이며 Vercel 비밀번호는 변경·동기화되지 않습니다.

NEW ROOM · 노트 B 새 방 생성

방 이름은 영문 소문자·숫자·_·- 1~50자, 비밀번호는 8자 이상·256바이트 이하입니다. 기존 방은 덮어쓰지 않습니다. 생성 즉시 지정한 비밀번호로 로그인할 수 있고 목록에도 나타납니다. 데이터 폴더는 첫 저장 또는 파일 업로드 시 만들어집니다.
